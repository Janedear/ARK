Save & share ARK

ARK makes its network from people's devices, so it helps more when the people near you have it too. The whole app is one file. They open it in any web browser. Nothing to install.

Save a copy of ARK

Saves a clean copy of the app to this device. None of your names, notes or messages are in it. Works with no internet.

Phone to phone (no internet needed)

The fastest way when someone is next to you.

  1. Save a copy of ARK with the button above
  2. Open your Files app and find ARK-CRISIS-SUITE.html
  3. Press and hold it, then tap Share. Choose AirDrop (iPhone) or Quick Share (Android)
  4. Pick the other person's phone

USB stick (no internet or Wi-Fi needed)

Works even when the power and phone networks are down.

  1. Save a copy of ARK on a computer
  2. Copy ARK-CRISIS-SUITE.html to a USB stick
  3. Carry the stick to whoever needs it
  4. They plug it in and open the file in a web browser
Tip: write "ARK. Open in a web browser" on the stick. Keep copies on more than one stick.

QR code (needs a hub)

If this device has joined an ARK Hub, others on the same Wi-Fi can scan a code to get ARK from the hub. No internet needed.

Send a link (needs internet)

Sends a link to arks.solutions. Good for getting people ready before anything happens. The link only opens while the internet works.

A note to send with the file

Copy this and send it along with the file:

I'm sending you ARK. It is a free emergency toolkit that works with no internet. In a crisis it makes its own local network from the devices around you: one laptop is the hub and nearby phones join it over Wi-Fi. Open the file in any web browser. Nothing to install. Keep it on your phone.
