ARK — Start here

This folder is the whole ARK kit. It works with no internet. Read this page once now, while things are normal.

In immediate danger

Call 911 (or your local emergency number). ARK is not an emergency service and nobody monitors it.

1. Use ARK on your own phone or computer

  1. Open the file ARK-CRISIS-SUITE.html in this folder. It opens in any web browser.
  2. Fill in your household plan and emergency contacts.
  3. Print the emergency card (Household tab) and keep a paper copy.

Everything you type stays on your own device.

2. Link the phones around you — with no internet

One laptop or Raspberry Pi becomes the hub. Every phone on the same Wi-Fi can then read and post messages.

  1. Windows: open the hub folder and double-click start-hub.cmd. If Windows Firewall asks, allow private networks.
    Mac, Linux, Raspberry Pi: open Terminal in this folder and run sh hub/start-hub.sh (Node.js must be installed).
  2. The hub window shows an address such as http://192.168.1.20:8080. Write it on paper, or open http://localhost:8080/sign and print the sign.
  3. Everyone joins the same Wi-Fi and types that address into their browser. A router that is switched on but has no internet is fine.

The message board is public to everyone on that Wi-Fi. Do not post anything you would not pin to a noticeboard.

3. Fill these in now

  • MEETING-POINT.txt — where your household meets if you cannot reach each other.
  • Emergency-Contacts.txt — local numbers you will not be able to look up later.
  • Household-Plan-Worksheet.txt — print it and fill it in by hand.

4. Pass it on

Copy this whole folder to a USB stick for a neighbour. Anyone on a hub's Wi-Fi can also tap Save full kit on the hub page.

Practise once before you need it: start the hub, join with two phones, post a message. More detail is in hub/HUB-GUIDE.md.
