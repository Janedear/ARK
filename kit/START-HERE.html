Start here

In a crisis, ARK makes its own internet from the devices around you.

One laptop becomes the hub. Nearby phones join it over Wi-Fi. Hubs pass messages on to each other by network, radio, or a USB stick. This folder is the whole ARK kit, and it works with no internet. Read this page once now, while things are normal.

In immediate danger

Call 911 (or your local emergency number) if any phone works. ARK is not an emergency service and nobody monitors it.

You are reading this from an ARK hub

Your phone has no kit folder, so use these instead of step 1.

1Use ARK on your own phone or computer

  1. Open the file ARK-CRISIS-SUITE.html in this folder. It opens in any web browser.
  2. Tap Plan and fill in your household plan and emergency contacts.
  3. On the same screen tap Print card, and keep the paper copy where everyone can find it.

Everything you type stays on your own device. This part needs no hub and no Wi-Fi.

2Link the phones around you, with no internet

One laptop or Raspberry Pi becomes the hub. Every phone on the same Wi-Fi can then read and post messages. A phone alone cannot be the hub.

  1. Windows: open the hub folder and double-click start-hub.cmd. If Windows Firewall asks, allow private networks.
    Mac, Linux, Raspberry Pi: open Terminal in this folder and run sh hub/start-hub.sh (Node.js must already be installed).
  2. The hub window shows an address such as http://192.168.1.20:8080. Write it on paper, or open http://localhost:8080/sign on the hub and print the sign.
  3. Everyone joins the same Wi-Fi and types that address into their web browser. A router that is switched on but has no internet is fine.

The network is local. Messages reach only people on this hub, and on other hubs it swaps messages with. The board is public to everyone on that Wi-Fi, so do not post anything you would not pin to a noticeboard.

3Fill these in now

  • MEETING-POINT.txt: where your household meets if you cannot reach each other.
  • Emergency-Contacts.txt: local numbers you will not be able to look up later.
  • Household-Plan-Worksheet.txt: print it and fill it in by hand.

4Pass it on

Copy this whole folder to a USB stick for a neighbour. Anyone on a hub's Wi-Fi can also tap Save the full kit on the hub page.

Practise once before you need it: start the hub, join with two phones, post a message. If the hub does not start or a phone cannot open the address, the fixes are in hub/HUB-GUIDE.md.
