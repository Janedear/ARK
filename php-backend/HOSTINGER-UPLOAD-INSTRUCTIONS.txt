WHAT YOU ARE UPLOADING
──────────────────────
  ARK-CRISIS-SUITE.html   ← the main app (open this in a browser)
  ark-bugs.php            ← receives bug reports from the app
  ark-patches.php         ← serves hot-patch updates to the app
  ark-admin.php           ← password-protected admin panel
  ark-data/               ← data folder (bugs and patches stored here)
    bugs/                 ← bug reports land here (keep this folder)
    patches/
      latest.json         ← current patch state (starts inactive)

WHERE TO PUT THEM
─────────────────
  Upload ALL files and folders to: public_html/
  (the root of your Hostinger website)

  Final structure on the server:
    public_html/
    ├── ARK-CRISIS-SUITE.html
    ├── ark-bugs.php
    ├── ark-patches.php
    ├── ark-admin.php
    └── ark-data/
        ├── bugs/
        └── patches/
            └── latest.json

HOW TO UPLOAD (Hostinger File Manager)
───────────────────────────────────────
  1. Log into Hostinger → hPanel
  2. Click "File Manager"
  3. Navigate to public_html/
  4. Click "Upload Files" and upload the .html and three .php files
  5. Create a folder called "ark-data" inside public_html
  6. Inside ark-data, create folders "bugs" and "patches"
  7. Upload ark-data/patches/latest.json into the patches/ folder

  Alternatively: zip the entire contents, upload the zip, and use
  File Manager's "Extract" feature to extract directly into public_html/

AFTER UPLOADING
───────────────
  App URL:    https://yourdomain.com/ARK-CRISIS-SUITE.html
  Admin URL:  https://yourdomain.com/ark-admin.php

  Default admin password: ARK-admin-2024
  ⚠️  CHANGE THE PASSWORD in ark-admin.php before uploading!
     Open the file, find line:
       define('ADMIN_PASSWORD', 'ARK-admin-2024');
     Change 'ARK-admin-2024' to your own password.

OPTIONAL: ENABLE EMAIL NOTIFICATIONS FOR BUG REPORTS
─────────────────────────────────────────────────────
  Open ark-bugs.php and uncomment the mail() block near the bottom.
  Hostinger shared hosting supports PHP mail() out of the box.

THAT'S IT — NO npm, NO build steps, NO Cloudflare, NO terminal.
Just upload and open.
