How ARK works

In a crisis, ARK makes its own internet from the devices around you.

One laptop is the hub. A laptop or Raspberry Pi runs the ARK Hub program. A phone alone cannot be the hub.
Nearby phones join it over Wi-Fi. They open the address below in a web browser. No app, no account, no internet.
Hubs pass messages on to each other by network, radio, or a USB stick. Messages reach only people on these hubs.

Carry messages by hand

No link between two hubs? Carry the messages on a USB stick or a phone.

  2. Copy the file to a USB stick, or keep it on your phone.
  3. Go to the other hub and open this same page there.
  4. Choose the file under "Bring messages in". That hub now has these messages too.
