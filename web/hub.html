ARK Hub

One laptop becomes the hub. The phones around you join in.

In a crisis, ARK makes its own internet from the devices around you. The hub is the laptop in the middle.

Every phone that joins the same Wi-Fi can post and read messages, open the first-aid guides, and save ARK for themselves. It works with no internet. The hub must run on a laptop or a Raspberry Pi — a phone on its own cannot be the hub.

Know the limits

The hub reaches about as far as your Wi-Fi does. Its message board is public to everyone on that Wi-Fi, so do not post anything private. Messages go no further unless your hub is linked to another hub.

ARK is not an emergency service and nobody monitors it. In immediate danger, call 911 or your local emergency number.

  1. Download and unzip — today

    Do this now, while you have internet. Copy the unzipped folder to a USB stick as a spare.

  2. Start the hub

    Windows: open the folder, open hub, and double-click start-hub.cmd. If Windows Firewall asks, tick Private networks and allow. Keep the window open: closing it stops the hub.

    Mac, Linux, Raspberry Pi: install Node.js once, while you have internet. Then run sh hub/start-hub.sh in the folder.

  3. Write down the address

    The window shows the hub's address, for example http://192.168.1.20:8080. Put it on paper where people can see it. To print a ready-made sign, open http://localhost:8080/sign on the laptop.

  4. Everyone joins

    Each phone joins the same Wi-Fi as the laptop and types that address into its browser. A router with no internet works. So does a phone hotspot, as long as the laptop joins it too. No app, no account.

    Phone cannot open it? Check it is on the same Wi-Fi as the laptop. Type the whole address, starting with http:// and not https://. Turn off mobile data on the phone and try again.

    Still nothing? On a Windows laptop, allow the hub through Windows Firewall on Private networks. On the router, turn off “guest mode” (also called “AP isolation”), which stops devices from seeing each other.

  5. Practise once

    Unplug your router from the internet, start the hub, join with two phones and post a message. Ten minutes now saves confusion later.
