ARK Hub

Link the phones around you — with no internet

One laptop becomes a local message board. Every phone that joins the same Wi-Fi can post and read messages, open the first-aid guides, and save ARK for themselves. Nothing leaves the room.

1. Download the hub kit (do this now, while you have internet)

Download the ARK Hub kit

Free. About 35 MB. Includes everything a Windows laptop needs. Unzip it, and copy the folder to a USB stick as a spare.

2. Start the hub

  1. Windows: open the unzipped folder, open hub, and double-click start-hub.cmd. If Windows Firewall asks, tick Private networks and allow.
  2. Mac, Linux or Raspberry Pi: install Node.js once, then open Terminal in the folder and run sh hub/start-hub.sh.
  3. A window shows the hub's address, for example http://192.168.1.20:8080. Write it on paper.

3. Everyone joins

  1. Each phone joins the same Wi-Fi as the laptop. A router that is switched on but has no internet works fine. So does a phone hotspot.
  2. They type the hub's address into their browser. That is all — no app, no account.

4. Practise once

Unplug your router from the internet, start the hub, join with two phones and post a message. Ten minutes now saves confusion later.

Know the limits

The hub reaches about as far as your Wi-Fi does. Its message board is public to everyone on that Wi-Fi. ARK is not an emergency service and nobody monitors it — in immediate danger, call 911.

The full guide is in the kit: hub/HUB-GUIDE.md. Source code: github.com/Janedear/ARK.
