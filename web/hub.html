ARK Hub

Link the phones around you.No internet needed.

One laptop becomes a local message board for a street, a building or a shelter.

Every phone that joins the same Wi-Fi can post and read messages, open the first-aid guides, and save ARK for themselves. Nothing leaves the room.

Download the hub kit Free · about 35 MB
Includes everything a Windows laptop needs.
Know the limits

The hub reaches about as far as your Wi-Fi does, and its message board is public to everyone on that Wi-Fi. ARK is not an emergency service and nobody monitors it. In immediate danger, call 911.

  1. Download and unzip — today

    Do this now, while you have internet. Copy the unzipped folder to a USB stick as a spare.

  2. Start the hub

    Windows: open the folder, open hub, and double-click start-hub.cmd. If Windows Firewall asks, tick Private networks and allow.

    Mac, Linux, Raspberry Pi: install Node.js once, then run sh hub/start-hub.sh in the folder.

  3. Write down the address

    A window shows the hub's address, for example http://192.168.1.20:8080. Put it on paper where people can see it.

  4. Everyone joins

    Each phone joins the same Wi-Fi as the laptop and types that address into its browser. A router with no internet works. So does a phone hotspot. No app, no account.

  5. Practise once

    Unplug your router from the internet, start the hub, join with two phones and post a message. Ten minutes now saves confusion later.
